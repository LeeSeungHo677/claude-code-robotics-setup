# /setup:tree

`~/.claude` 에 무엇이 있고 각각 **어떻게 열리는지**를 한 화면 도식으로 본다.
스킬 91개를 카테고리별로, 에이전트·커맨드·훅까지 트리로 그린다.

## Steps

1. 아래를 실행하고 **출력을 그대로 보여준다.**

   ```bash
   python3 ~/.claude/bin/setup-tree.py $ARGUMENTS
   ```

2. **출력을 다시 요약하거나 목록을 옮겨 적지 않는다.** 도식이 이미 답이다.
   덧붙일 것은 사용자가 물은 것에 대한 한두 줄뿐이다.

3. 출력 끝에 `! 유령 스킬` / `! 유령 에이전트` 경고가 있으면 그것만 짚는다 —
   분류표(`~/.claude/bin/setup-tree.py` 의 `SKILL_GROUPS`)와 디스크가 어긋났다는 뜻이다.
   새로 생긴 스킬은 `미분류` 그룹에 모여서 보인다.

## Gotchas

- **터미널에서 직접 돌리면 토큰을 전혀 안 쓴다** — `! python3 ~/.claude/bin/setup-tree.py`.
  사용자가 그냥 훑어보려는 것이면 이쪽을 권한다. 파이프로 나갈 때는 색이 자동으로 꺼진다.
- 인자는 이름과 description 양쪽에 걸린다. `/setup:tree 안전` 처럼 한국어도 된다.
- 전체 출력은 약 110줄, `-d` 는 약 170줄이다. 사용자가 특정 영역만 물었으면
  **인자를 붙여서** 그 부분만 띄운다. 전체를 띄우고 눈으로 찾게 하지 않는다.
- 사용법 설명(어떤 상황에 무엇을 쓰는가)은 `/setup:guide`, 구성 점검은 `/setup:audit`.
  이 커맨드는 **무엇이 있는지 지도**만 보여준다.
