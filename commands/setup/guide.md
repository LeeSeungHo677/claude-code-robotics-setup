# /setup:guide

`~/.claude/README.md` 가 이 세팅의 사용 설명서다 (약 20KB, 12개 절).
**전부 읽어서 그대로 출력하지 않는다.** 사용자가 물은 범위만 꺼낸다.

## Steps

1. **인자가 있으면** — `~/.claude/README.md` 에서 그 주제에 해당하는 절만 읽어 답한다.
   README 에 없으면 `~/.claude/skills/` 와 `~/.claude/agents/` 의 description 을
   grep 해서 관련 있는 것을 찾는다.

2. **인자가 없으면** — 아래를 한 화면에 보여준다. README 를 통째로 읽을 필요 없다.

   - **지금 이 디렉토리에서 바로 쓸 것** — 세션 시작 컨텍스트의 "여기서 쓸 만한 것" 을 재사용
   - **세 가지 사용법**: ① 그냥 말한다(스킬이 자동으로 열림) ② `/커맨드` ③ 에이전트 호출
   - **개수**: 스킬 · 에이전트 · 커맨드 · 훅이 각각 몇 개인지 (실제로 세서 말한다)
   - **자동으로 막히는 것**: `~/.claude/hooks/` 의 가드 4종 요약
   - **더 볼 곳**: `/setup:tree` (무엇이 있는지 전체 도식) ·
     `~/.claude/README.md` (전체) · `~/.claude/MANIFEST.md` (변경 이력·판단 근거)

3. 개수를 말할 때는 **문서에 적힌 숫자를 믿지 말고 직접 센다.**
   README 의 숫자는 낡기 쉽다 (실제로 2026-08-17 에 78→88 로 어긋나 있었다).
   개수·목록을 세야 하면 손으로 세지 말고 `python3 ~/.claude/bin/setup-tree.py` 를 쓴다.

## Gotchas

- 스킬은 **부르는 게 아니라 열리는 것**이다. 사용자가 관련된 말을 하면 자동으로 열린다.
  "무슨 스킬 써?" 라고 묻지 말고 그냥 하려는 일을 말하면 된다고 안내한다.
- 에이전트는 반대로 **이름을 불러야 온다.** `~/.claude/CLAUDE.md` 에 호출 기준이 있는
  3개(`ros2-reviewer`·`robot-safety-reviewer`·`robotics-architect`)를 먼저 안내한다.
- 프로젝트 스코프(`<repo>/.claude/`)와 유저 스코프(`~/.claude/`)를 구분해서 말한다.
  프로젝트 것은 그 레포에서만 보인다.
- 지식은 `~/knowledge/` 에 쌓인다 (논문·로봇 분석·분석 산출물). 레포에 넣지 않는다.
