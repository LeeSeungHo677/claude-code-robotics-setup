# 매니퓰레이션 제어 · 파지

## 제어 방식 선택

| 상황 | 제어 |
|---|---|
| 자유 공간 이동, 접촉 없음 | 위치 제어 (관절 궤적 추종) |
| 환경과 접촉하지만 힘 정밀도는 불필요 | **임피던스 제어** |
| 접촉력을 명시적으로 조절해야 함 | **어드미턴스 제어** 또는 힘 제어 |
| 일부 축은 위치, 일부는 힘 (예: 표면 연마) | 하이브리드 위치/힘 제어 |
| 사람과 물리적 상호작용 | 임피던스 + 안전 규격 준수 |

### 임피던스 vs 어드미턴스 — 헷갈리면 안 된다

- **임피던스 제어**: 위치 오차를 입력받아 **힘/토크를 출력**한다.
  `τ = K(x_d − x) + D(ẋ_d − ẋ)` — 토크 제어가 가능한 로봇에 적합.
  기구가 부드럽고(backdrivable) 힘 센서 없이도 가능. 충돌에 본질적으로 안전.
- **어드미턴스 제어**: 측정된 **힘을 입력받아 위치 명령을 출력**한다.
  힘/토크 센서가 필수. 위치 제어만 가능한 산업용 로봇에 적용 가능.
  강성이 높은 로봇에서는 접촉 시 불안정해지기 쉽다.

**선택 기준은 로봇의 하부 제어 인터페이스**다. 토크 제어가 되면 임피던스,
위치 명령만 받으면 어드미턴스.

### 파라미터 튜닝
- 강성 K 는 **작업 축마다 다르게** 준다. 삽입 작업이면 삽입 방향은 강하게,
  나머지 방향은 부드럽게 — 이게 접촉 작업 성공의 핵심이다.
- 감쇠 D 는 임계 감쇠 근처에서 시작한다: `D ≈ 2·ζ·sqrt(K·M)`, ζ≈0.7~1.0.
  D 가 부족하면 진동하고, 과하면 굼뜨다.
- 강성을 낮출수록 안전하지만 정밀도가 떨어진다. **정밀도가 필요한 구간만 강하게** 하고
  접근·탐색 구간은 부드럽게 하는 단계적 설계가 실무 정답이다.

## 힘/토크 센서

- **중력·페이로드 보상**이 먼저다. 보상 없이 읽은 힘은 대부분 로봇 자신의 무게다.
  툴 장착 후 자세를 여러 개 취하며 툴 질량·무게중심을 추정한다.
- **바이어스 제거**: 접촉 없는 상태에서 영점을 잡는다. 온도 드리프트가 있으므로
  작업 시작 전마다 재영점을 권장한다.
- 센서 좌표계 → TCP 좌표계 변환을 명확히 한다. 부호가 뒤집히면 로봇이 밀어야 할 때 당긴다.
- 노이즈 필터링과 지연은 트레이드오프다. 저역통과 차단주파수를 낮추면 안정적이지만
  충돌 감지가 늦어진다. **충돌 감지는 별도 경로**로 빠르게 처리한다.

## 접촉 작업 (peg-in-hole 등)

1. **접근**: 위치 제어로 구멍 근처까지 (여유 있게)
2. **탐색**: 부드러운 강성으로 나선/리사주 운동하며 접촉 탐지
3. **정렬**: 접촉력의 방향으로 자세를 보정
4. **삽입**: 삽입 축은 힘 제어(일정 힘 유지), 횡방향은 낮은 강성
5. **검증**: 삽입 깊이 또는 힘 프로파일로 성공 판정

- **성공 판정 기준을 수치로 정의**한다. "들어간 것 같다" 는 자동화가 아니다.
- 실패 시 재시도 전략(빼고 다시, 위치 조금 이동)을 미리 정의한다.
- 힘 한계를 넘으면 **즉시 정지**한다. 밀어붙이면 부품이나 로봇이 망가진다.

## 그리퍼 제어

### 평행 그리퍼
- 위치·속도·힘(전류) 제어 모드를 구분한다. 파지는 대개 **힘 제한 하의 위치 제어**.
- 파지력이 너무 강하면 물체가 변형되고, 약하면 미끄러진다.
  물체별 파지력을 파라미터로 관리한다 — 코드에 상수로 박지 않는다.
- **파지 성공 확인**: 그리퍼 개폐량이 예상 범위인지 확인한다.
  완전히 닫혔으면 물체를 놓친 것이고, 전혀 안 닫혔으면 헛짚은 것이다.
  이 확인을 안 하면 빈 손으로 다음 단계를 진행한다.
- ROS 2 에서는 `GripperCommand` 액션 또는 전용 인터페이스. `ros2-control` 스킬 참고.

### 흡착(suction)
- 진공압 센서로 파지 확인. 압력이 임계 이하로 안 떨어지면 실패.
- 표면 조건에 민감하다 — 곡면, 다공성, 젖은 표면에서 실패한다. 물체 종류를 먼저 확인한다.
- 파지 후 이동 중 압력을 계속 감시한다. 떨어지면 즉시 감속·정지.

### 다지 핸드
- 자유도가 많아 제어가 복잡하다. 대개 사전 정의된 파지 자세(grasp primitive) 몇 개로 시작한다.
- 각 손가락의 접촉 시점이 다르므로 동시 제어보다 **순차 폐쇄**가 안정적이다.

## 파지 계획

- **해석적 방법**: antipodal 파지점 탐색 — 물체 메시/포인트클라우드에서 마주보는 면을 찾는다.
  형상을 알 때 빠르고 설명 가능하다.
- **학습 기반**: 포인트클라우드/RGB-D 에서 6-DoF 파지 후보와 점수를 예측.
  미지 물체에 강하다. 후보를 여러 개 받아 **도달 가능성(IK)과 충돌로 필터링**한다.
- 파지 후보를 그대로 실행하지 않는다. 필터 순서:
  1. IK 해 존재 2. 접근 경로 충돌 없음 3. 파지 안정성 점수 4. 후속 작업에 유리한 자세
- **접근(pre-grasp) 자세**를 별도로 둔다. 물체 위 10 cm 에서 직선 접근하는 구조가
  충돌과 실패를 크게 줄인다.
- 파지 후 물체를 `attached_collision_object` 로 등록한다 (`motion-planning` 스킬).

## 안전

- 사람과 공간을 공유하면 힘·속도 제한이 규격 요구사항이 된다 (`robot-safety-compliance` 스킬).
- 예상치 못한 접촉 감지 → 정지 경로는 **제어 루프와 독립**이어야 한다.
- 그리퍼는 전원이 나가도 물체를 놓지 않는 구조(기계식 자기유지)를 권장한다.
  전원 차단 시 물체가 떨어지면 그 자체가 사고다.
